# Population-Insight 答辩材料

## 项目简介

`Population-Insight` 是一个基于 Python、Flask、SQLite、Matplotlib 和 ECharts 的人口趋势与分析管理系统。系统围绕人口年度核心数据，提供数据采集、数据管理、查询筛选、统计排名、图表可视化、机器学习趋势预测、智能风险评估、分析报告和 CSV 导出等功能。

## 技术架构

- 后端：Flask 路由层 + 服务层函数 + SQLite 数据库。
- 前端：Jinja2 模板、CSS、JavaScript、ECharts。
- 数据库：8 张核心表，覆盖用户、人口数据、地区档案、数据来源、扩展指标、年度指标值、分析报告和操作日志。
- 预测模型：线性回归、复合增长率、近期趋势拟合和融合预测。
- 解释分析：支持 OpenAI 兼容大模型接口；未配置接口时使用本地规则解释。

## 核心功能清单

1. 用户登录与权限验证。
2. 人口数据采集：支持公开 URL 和粘贴表格文本。
3. 人口数据新增、修改、删除、查询。
4. 多条件筛选和排序。
5. 多地区指标对比分析。
6. 统计分析与地区排名。
7. 趋势图、柱状图、性别结构饼图和预测图表。
8. 机器学习人口趋势预测。
9. 老龄化、低出生率、负自然增长等风险识别。
10. 大模型或本地规则解释预测结果。
11. 地区档案、数据来源、扩展指标和年度指标值管理。
12. 分析报告生成与保存。
13. CSV 数据导出。
14. 操作日志审计。

## 数据表说明

| 表名 | 作用 |
| --- | --- |
| `users` | 存储用户名、密码哈希、角色和创建时间 |
| `population_data` | 存储地区、年份、总人口、性别人口、出生率、死亡率、老龄化率、城镇化率等核心指标 |
| `operation_logs` | 记录新增、修改、删除、采集、扩展维护等操作 |
| `regions` | 存储地区名称、地区类型、行政区划代码、上级地区和备注 |
| `data_sources` | 存储来源名称、发布机构、来源链接、发布日期、可信等级 |
| `population_indicators` | 存储扩展人口指标定义 |
| `annual_indicator_values` | 存储某地区、某年份、某扩展指标的具体数值 |
| `analysis_reports` | 存储报告标题、筛选条件摘要、分析摘要和创建时间 |

## 演示流程建议

1. 使用 `admin / admin123` 登录系统。
2. 进入概览页，展示记录数量、地区数量、年份范围和最新操作日志。
3. 进入数据采集页，粘贴一段 CSV 人口表格，演示预览和导入。
4. 进入数据管理页，演示地区、年份、人口区间、出生率区间、老龄化率区间筛选。
5. 演示按总人口、年份、出生率、老龄化率排序。
6. 进入对比分析页，选择北京市和广东省，展示年度对比图、最新排名和变化幅度。
7. 进入统计分析页，展示平均值、最大最小值、增长率和地区排名。
8. 进入图表中心，展示趋势图、柱状图和性别结构饼图。
9. 进入趋势预测页，展示机器学习预测结果、风险评估和解释分析，并保存为分析报告。
10. 进入分析报告页，查看刚保存的报告。
11. 进入预警分析页，展示老龄化、负自然增长和低出生率预警。
12. 进入扩展指标页，演示指标定义和年度指标值录入。
13. 在数据管理页导出 CSV。
14. 进入操作日志页，展示系统审计能力。

## 创新点

- 将传统人口数据管理与趋势预测结合，形成“数据采集 - 管理 - 分析 - 预测 - 报告”的完整闭环。
- 使用线性回归、增长率拟合和近期趋势融合，避免单一预测方法带来的偏差。
- 引入大模型解释分析接口，能够把数值预测转换为管理者可读的分析文本。
- 支持多地区、多指标、年份区间的横向对比，便于展示地区差异。
- 系统保留 Web 端和控制台端两个入口，适合课程演示和命令行备用运行。

## 答辩问答准备

**Q：为什么使用 SQLite？**  
A：系统定位是课程设计和小型数据分析应用，SQLite 免部署、易迁移，适合展示数据库表设计、增删改查、约束和查询分析。

**Q：预测模型为什么不用复杂深度学习？**  
A：样例数据规模较小，复杂模型容易过拟合。线性回归和增长率拟合更适合小样本年度统计数据，也更容易解释。

**Q：大模型解释是否必须联网？**  
A：不是。系统支持 OpenAI 兼容接口；如果没有配置接口，会自动使用本地规则解释，保证离线演示也能运行。

**Q：权限如何控制？**  
A：系统区分 `admin` 和 `viewer`。管理员可以采集、维护和删除数据；普通用户主要负责查询、分析、预测、导出和查看报告。

**Q：如何保证数据质量？**  
A：系统在录入和采集导入时校验年份范围、非负数值、性别人口合计、地区年份唯一性和指标编码存在性。
